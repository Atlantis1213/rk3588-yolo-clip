# CLIP-only、非YOLO裁剪评估

## 协议与范围

用户要求先绕过YOLO，以其他裁剪方式评估CLIP。复用此前冻结的真实200张：
cycle/harmful/kitchen/others/empty各40张。未重采样、剔除困难样本或用于校准训练。
源目录远端`H:/Race/25工创/wastesorting_data/2025_7_25`仅发现7817张JPG，未发现人工框文件。

先阅读原项目`src/auto_label/foreground.py`的HSV/连通域方法。原35–95 H、35–255 S
背景范围把带绿幕色偏的中性物体也抹掉，160个非空中112个无框，部分框只含标签/反光。
没有据此给CLIP报分。之后固定S下限180，其他形态学/面积条件保持；156个有前景，
4个无框。逐图检查160组原图/裁剪，发现透明瓶、小目标和盘面误定位等28处问题。

最终输入方案：132张用固定HSV连通域加12%留边；28张视觉检查发现有问题的图用
统一保守中央ROI（320x180预览坐标[75,5,245,175]，即1280x720源图[300,20,680,680]），
避免只截取瓶盖、反光或丢掉目标。40张empty仍完整输入，由CLIP实际判断，不直接赋empty。
旧裁剪尝试保留，最终冻结在`nonyolo_reviewed_crop_v2`，首次CLIP评分后不再修改裁剪。

视觉检查由助手完成，不是人工真值框标注；宽中央ROI不是精确物体边界。
这组分数反映**非YOLO、视觉核验裁剪条件下的分类**，不能当作自动裁剪系统准确率、
端到端YOLO检测准确率或新的独立盲测。已知empty标签选择整图分支，也不是在线自动判空。

- 固定原29标签/文本bank、拒绝阈值0.22，不根据结果改提示词或阈值。
- 板端同一CLIP预处理器：224直接resize、RGB、原mean/std、IEEE FP16舍入。

- 历史部署RKNN、研究FP16、KL120混合和已预先固定的RepQ LN1+LN2候选串行NPU测试。

  直接算跨契约RMSE。摄像头、YOLO、RGA/DMA吞吐均不属于本轮结果。
- 默认模型/部署配置/系统Runtime不替换；模型测试通过隔离Runtime2.3.2运行。

## 最终结果（所有模型已完成）

| 版本 | 全部200张 | 非空160张 | 空图40张 |
| --- | ---: | ---: | ---: |
| 研究FP32 ONNX | 175/200=87.5% | 135/160=84.375% | 40/40 |
| 研究FP16 RKNN | 175/200=87.5% | 135/160=84.375% | 40/40 |
| 历史部署RKNN | 176/200=88.0% | 136/160=85.0% | 40/40 |
| KL120混合量化 | 165/200=82.5% | 127/160=79.375% | 38/40 |
| RepQ式LN1+LN2混合量化 | 165/200=82.5% | 126/160=78.75% | 39/40 |

FP16对FP32的单位特征平均余弦0.9998202、单位输出SQNR34.44 dB。
历史部署对研究FP32平均余弦0.9744079、单位SQNR12.91 dB；历史多分对1张
不能据此说数值保真优于同源FP16，也不是统计上已证明识别能力更强。
准确率相同不表示所有逐样本预测一致，完整预测列表保留在评估文件中。

KL120比同源FP16低5个百分点。本批浮点错误25张，其中cycle10、harmful7、kitchen7、
others1、empty0。比如皱纸被分为tissue，纸杯被分为ceramic cup或empty background；
这些是固定标签bank下的实际错误例子，不证明唯一原因，也没有据此调整bank/提示词。
RepQ在本轮总正确数与KL相同，非空少1张、empty多1张，未复现此前YOLO候选ROI上
83.5%对79%的优势。因此不据上一组分数直接采用它，也不根据本轮结果修改裁剪。
其单位特征平均余弦0.852255、SQNR5.29 dB高于KL的0.833321、4.77 dB，
但方向重建改善没有转化为本轮总分类准确率提高。

完整证据：`clip_only_evaluation.json`。测试状态completed，5个版本均有完整200行输出。
完成后重新校验全部200个裁剪和输入SHA，均未变化。板端RepQ临时模型副本已清理，
本机完整候选及板端全部输出保留；默认模型与系统配置不变。

当前可表述为：**在固定29标签、拒绝阈值0.22和已核验非YOLO裁剪下，本批200张
原部署CLIP分类88%，同源研究FP32/FP16 87.5%，两种混合量化82.5%。**
仅看160张有垃圾图片，分别为85%、84.375%、79.375%/78.75%。
这是本批样本和当前标签体系下的结果，不等于任意垃圾场景的泛化准确率。
